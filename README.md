## Run locally

This is a static website and does not require a build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/Harishvw24/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in a browser, or serve the project with a local HTTP server:

   ```bash
   npx serve .
   ```

3. Open the local URL shown in the terminal.
